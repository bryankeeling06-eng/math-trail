# Math Trail

A kid-friendly side-scrolling math runner for ages 5–6. One HTML file plus short voice clips. No build step.

**Play:** https://bryankeeling06-eng.github.io/math-trail/

**Costume preview (admin):** https://bryankeeling06-eng.github.io/math-trail/?admin=1

If those links 404 for a minute after a push, GitHub Pages is still building — wait ~30–60 seconds and refresh.

## Play on a phone or send to a friend

Open the Play link above. Stars, owned costumes, and mute stay saved in that browser.

## What it does

- Mode select: Addition, Subtraction, or Mixed
- Numbers stay 0–9 (no double-digit answers)
- Slow pace for 5–6 year olds; speed ticks up a little after every 5 correct gates
- Correct answer: runner rushes the gate and front-flips over it
- 3 lives, bonus-life math question after game over
- Costume shop paid with stars; extra characters unlock at levels 15 / 25 / 30 / 35
- Recolor costumes, mute, pause
- Kid-voice cheers (and a speech fallback if audio is blocked)

## Files

- `index.html` — game
- `voices/` — short cheer / miss clips
- `.nojekyll` — tells GitHub Pages not to run Jekyll

## Keep editing

Yes. Change the files, push to `main`, and the Play link updates. Pages stays the same URL.
